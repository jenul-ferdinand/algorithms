This repository is named `algorithms/`. It consists of the work done by the student during university for their subjects in computer science:

- `fit1008/`: Fundamentals of algorithms _(complete)_

- `fit2004/`: Algorithms and data structures _(complete)_

- `fit3155/`: Advanced data structures and algorithms _(in-progress)_
    - **Overview:** This unit builds on the concepts learnt in introductory algorithms and data structures study. It covers advanced algorithmic paradigms and problem-solving techniques required to address real-world programming challenges. It explores, in depth, the design and analysis of space-efficient data structures and time-efficient problem solving strategies to be used with them. Topics include amortized analysis, advanced sorting and searching algorithms, new tree/string/graph data structures and algorithms, and number-theoretic algorithms amongst others.
    - **Learning Outcomes:** On successful completion of this unit, the student should be able to, (1) Analyse efficient data structures and effective algorithmic paradigms; (2) Design and implement efficient algorithms and data structures for use on large data sets; (3) Apply advanced algorithms and data structures to tackle complex computational problems; (4) Prove the correctness of programs and reason about their space and time complexities.
    - **Assessments:** Two assignments (weighted 20% + 20% = 40%), one final exam (weighed 60%). We are working on the assignments in `ass01/` and `ass02/`.
    - **Structure:** The folders are organised,
        - Into weeks i.e., `wkXX` where `XX` is the week number. Within the week folders, you'll find,
            - `LEARNING_INTENTIONS.md`: the learning intentions for that week.
            - `seminarXX.pdf`: the slides from the lecture for the current week's teachings. Also `seminarXX.vtt` which is the transcript from the lecture.
            - `notesXX.pdf`: the section from the unit textbook for the current week's teachings.
            - `src/`: contains my own implementations for the teachings of current week.
            - `labXX/`: contains my solutions to the problems for the `labXX.pdf` sheet for the current week's topic. Note that the unit physically runs the lab class in the following week (e.g. wk04's lab class is held in week 5), but the sheet is filed with the topic it covers, not the week it is taught. Solutions to the lab questions may also be found in `labXX-solutions.pdf`.
            - `questions/`: contains my solutions to questions found in `notesXX.pdf` for the current week.
