# Question 1: Does Z_1 matter?

We define Z-values for 2 <= i <= n, but what about Z_1? What would it be for the example above? Is this always the case? How much does this tell us about the structure of the string?

Example: S = aabcaabxaay

## Answer

For the string S, Z[1] = 11 because the matching prefix of the prefix is literally the whole string.

We only care about the Z-values for 2 <= i <= n because the Z[1] value is not useful practically.

But Z[1] does have one possibly useful property, it tells us how long the string is.
