# Question

Assuming as input a string, S[1..n], show that the time complexity of the naive method of constructing a suffix tree presented above is O(n^2).

# Answer

Let n be the length of the input string S.

To create the suffix tree naively we have to insert n suffixes, let i be the current suffix being inserted.

For every suffix i we always start the insertion process from the root node of the tree.

But the cost of insertion is not O(1), we have to pick the right spot to insert a new edge and leaf node for suffix i.

This means that on insertion of suffix i we have to walk down the tree comparing edge labels, in the worst case, there may be n comparisons when doing so.

Therefore the time complexity of building a suffix tree naively is O(n^2).
